Social Post Metadata Extractor Terms

Permitted Use

Social Post Metadata Extractor may be used to extract explicitly stated platform, post time, topic, and asset requirement fields from user-provided social posting request text.

User Responsibility

Users should submit only text they have the right to process and should remove sensitive or unnecessary personal data before submitting text.

Limitations

The app extracts only explicitly stated fields. It does not infer missing values, guess platform, guess post time, generate topics, create asset requirements, or make strategy decisions.

No Operational Actions

The app does not write social posts, generate captions, publish posts, schedule posts, send messages, update calendars, create assets, contact external parties, or modify external systems.

No External System Writes

The app is stateless, read-only, unauthenticated, does not store submitted data, does not call external APIs, and does not write to social media platforms or downstream systems.

Data and Privacy

Data handling is described on the privacy page. The app processes only submitted post_text and returns structured extraction output.
